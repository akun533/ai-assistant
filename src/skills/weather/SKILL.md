# Weather Skill

Get current weather for any location. No API key required - uses wttr.in service.

## Usage

```bash
# Basic weather
<skill:weather>Beijing</skill>
```

## Output Format

```
Weather Report for Shanghai

Temperature: 28°C (82°F)
Humidity: 65%
Wind: 15 km/h SW
Weather: Partly Cloudy
Feels Like: 30°C
```
